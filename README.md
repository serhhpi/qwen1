Инструкции по запуску:
Установите зависимости: pip install -r requirements.txt
Получите API-ключ для Qwen (DashScope).
Замените "YOUR_DASHSCOPE_API_KEY" в app.py на свой ключ или установите переменную окружения DASHSCOPE_API_KEY.
Убедитесь, что prompts.yaml находится в корне проекта.
Запустите сервер: python app.py
Перейдите в браузере на http://localhost:8000
Загрузите Excel-файл, нажмите "Обработать", скачайте результат.
